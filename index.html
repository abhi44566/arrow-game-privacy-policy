Welcome to Arrow Game, developed and published by PreeTech.

Your privacy is important to us. This Privacy Policy explains how Arrow Game handles information when you use our mobile application.

Arrow Game is designed as a lightweight, family-friendly game with a focus on simple gameplay and local data storage.

By using Arrow Game, you agree to the practices described in this Privacy Policy.

1. Information We Handle

Arrow Game may handle limited information required to provide the game's functionality. Depending on how you use the application, this may include:

Game Information

The application may store:

  • Game scores
  • Level progress
  • Completed levels
  • Difficulty/progression information
  • Game settings
  • Audio preferences
  • Other gameplay-related preferences

This information is primarily used to provide and maintain your gameplay experience.

Login Information

If the application asks you to enter a mobile phone number for player identification or login, the number may be stored locally on the device for the purpose of maintaining the player's local game session.

Arrow Game does not use the phone number for advertising or selling personal information.

Important Transparency Note

If a future update enables network-based login or OTP verification, phone number transmission details will be updated transparently in this section.

2. Local Data Storage

Arrow Game uses local storage/database technologies, including SQLite where applicable, to maintain game information on the player's device.

Examples include:

  • Game progress
  • Scores
  • Level information
  • Preferences
  • Local player/session information

This allows the game to maintain gameplay information between sessions.

The locally stored information is intended to remain on the player's device unless the application or operating system provides functionality that causes the data to be removed or reset.

If the application is uninstalled, locally stored application data may also be removed by the operating system.

3. Data Collection

Arrow Game is designed to minimize data collection. The game does not intentionally collect unnecessary personal information.

The application does not intentionally collect:

  • Contact lists or address books
  • Photos or videos
  • Precise location information
  • Device contacts
  • Microphone recordings
  • Camera images
  • SMS messages

unless a future version explicitly introduces a feature that requires such information.

4. Data Sharing

We do not sell or rent users' personal information.

Arrow Game is not designed to share users' personal information with third parties for advertising purposes.

Gameplay information stored locally on the device is not intentionally shared with external parties.

If any future version introduces third-party services, analytics, advertising, cloud synchronization, authentication providers, payment services, or other external services that process user information, this Privacy Policy will be updated accordingly.

5. Advertising

The current version of Arrow Game is intended to provide an ad-free gameplay experience.

The application does not intentionally use personal information for personalized advertising.

If advertising is introduced in a future version, the Privacy Policy will be updated to explain the relevant advertising technologies and data practices.

6. Analytics and Tracking

Arrow Game is designed without unnecessary tracking.

The application does not intentionally track users' activities across other applications or websites.

The application does not intentionally create advertising profiles based on users' gameplay activity.

If analytics or other tracking technologies are introduced in a future version, this Privacy Policy will be updated before or when those features are introduced.

7. Children's Privacy

Arrow Game is designed to be family-friendly and suitable for children and players of different ages.

We do not intentionally request children to provide unnecessary personal information. The game experience is designed to minimize the amount of personal information required to play.

Parents or guardians who have questions about information handled by the application may contact us using the contact information provided below.

If a parent or guardian believes that a child has provided personal information that should not have been provided, please contact us so that we can review the matter.

8. Data Security

We take reasonable steps to protect information handled by the application.

Game-related information stored locally is handled using the storage mechanisms implemented by the application and the security capabilities provided by the device operating system.

We do not claim that any electronic storage method or transmission method is completely secure.

9. Data Retention

Information stored locally by Arrow Game may remain on the player's device until:

  • The player removes it through available application functionality;
  • The application clears the relevant information;
  • The application is uninstalled; or
  • The device operating system removes the application data.

Because much of the game's data is stored locally, PreeTech does not maintain a central copy of ordinary gameplay progress unless a future version specifically introduces a cloud-based feature.

10. Account and Login Data

If Arrow Game provides a phone-number-based login or player identification feature, the information required for that feature may be stored or processed according to the actual implementation of the application.

The login information is intended to support access to the game and maintain the player's session.

It is not intended to be used for selling personal information or targeted advertising.

11. Third-Party Services

The current Arrow Game privacy practices reflect the services actually included in the released application.

If the application incorporates third-party services in future releases (such as Firebase, analytics, advertising networks, crash reporting, OTP/SMS providers, cloud databases, or payment providers), those services will be explicitly disclosed here with details on what information they process and why.

12. Permissions

Arrow Game requests only the permissions required for its actual functionality.

The application is not intended to access unnecessary personal information. Any permissions used by the application are clearly connected to a feature of the game.

If permissions change in a future release, this Privacy Policy will be reviewed and updated accordingly.

13. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes to the application, legal requirements, or our data practices.

When changes are made, the updated policy will be published on this page and the effective date will be updated.

We encourage users and parents/guardians to review this page periodically.
